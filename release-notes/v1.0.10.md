## 更新内容

- 将配置、路径规则、SeaweedFS 网络访问、模型资源解析、后台任务和预览控件从主窗口拆分为独立模块。
- 使用统一任务管理器维护目录加载、单文件保存、递归保存和预览任务的启动、取消及线程回收。
- 单文件保存迁移到后台线程，并通过临时文件下载后原子替换目标文件。
- 目录加载和递归保存增加线程安全取消；关闭主程序时会取消并等待全部后台任务结束。
- 远端文件路径增加 URL 编码，递归保存和 GLTF 外部资源增加本地路径越界保护。
- 递归目录扫描使用双端队列并防止重复目录循环。
- 增加配置、URL、路径安全、原子下载、取消令牌和 GLTF 资源解析单元测试。
- 调整 GitHub Actions：PR 和主分支只检查、构建，只有匹配版本号的 tag 才发布 Release。

## 说明

- 网络取消会在当前读取操作返回后生效，最长等待时间仍受 HTTP 读取超时影响。
- 本阶段重点是架构和任务生命周期；大目录增量分页、连接池及并发递归下载留待下一阶段。
