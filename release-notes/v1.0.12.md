# SeaweedFS Browser v1.0.12

第五阶段增加 SeaweedFS Filer 写入能力。

## 新功能

- 在当前目录创建远程文件夹。
- 一次选择并上传多个本地文件，同名文件默认覆盖。
- 文件上传使用原始 `PUT` 流式传输，大文件不会整体载入内存。
- 上传批次默认最多并发 3 个文件，并提供非模态进度与取消操作。
- 批次中的单项失败不会中断其他文件，完成后可只重试失败项。
- 上传结果支持服务端 `Content-MD5` 完整性校验。

## 一致性与安全

- 文件夹名称禁止路径分隔符、`.`、`..` 和控制字符。
- 同名远程目录不会被文件上传覆盖。
- 写入完成、失败或取消后精确失效目标目录缓存，并在必要时重新加载。
- 用户切换目录后，后台写入完成不会强制跳回原目录。

## 配置

- 新增 `upload_workers`，默认值为 `3`，硬上限为 `16`。
