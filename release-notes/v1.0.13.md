# SeaweedFS Browser v1.0.13

第六阶段将上传、下载、目录加载和预览准备统一为可观察、可取消的后台任务。

## 统一任务架构

- 新增明确的任务类型、生命周期、进度单位和结构化错误模型。
- 任务运行时统一管理后台线程、并发上限、重复任务、取消和退出回收。
- Worker 只负责业务执行并发出标准事件，主窗口不再分别维护进度对话框和线程状态。
- 任务历史只保存展示所需快照，不持有文件内容或批量结果等大型业务对象。

## 任务中心与状态栏

- 新增可停靠任务中心，集中展示任务状态、阶段、进度、详情和取消操作。
- 状态栏自动选择最高优先级任务，并在多个后台任务并行时显示任务总数。
- 成功、失败和取消任务保留最近 50 条历史，可一键清除已完成任务。
- 递归保存目录不再阻塞浏览器主界面，可以在后台保存期间继续浏览。

## 稳定性

- 上传、下载、预览和目录任务继续沿用既有并发上限，避免无界线程增长。
- 同一预览继续按服务与远程路径去重。
- 关闭应用时通过统一任务运行时发出取消并等待线程安全退出。
- 增加任务状态、优先级、取消、成功与失败负载隔离测试。
