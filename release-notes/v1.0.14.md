# SeaweedFS Browser v1.0.14

第七阶段为桌面应用引入完整的多语言基础设施。

## 多语言

- 首批支持简体中文、English 和 Français。
- 新增“语言”菜单，切换后立即刷新主窗口、目录列表、任务中心和状态栏。
- 语言选择写入 `config.json`，下次启动以及 F3D 预览子进程会继续使用所选语言。
- 中文作为默认和缺失翻译的安全回退语言。

## 覆盖范围

- 翻译主窗口、菜单、表头、上下文菜单和文件选择提示。
- 翻译上传、下载、目录创建、预览及错误对话框。
- 翻译任务状态、进度阶段、任务中心操作和状态栏摘要。
- 翻译路径校验、HTTP 客户端、并发调度和 F3D 自检错误。
- 自定义确认、取消和关闭按钮，避免按钮语言跟随操作系统而与应用选择不一致。

## 质量保障

- 检查英文和法文目录拥有完全相同的源文本键。
- 检查所有占位符在三种语言中保持一致。
- 扫描代码中的 `tr(...)` 调用，阻止未登记的新界面文本进入构建。
- 增加语言规范化、回退和配置持久化测试。
