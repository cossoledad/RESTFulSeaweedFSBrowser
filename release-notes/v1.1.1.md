# SeaweedFS Browser v1.1.1

本版本增强了无 SeaweedFS 环境下的本地使用体验，并改进了 GLB/GLTF 模型预览。

## 本地文件系统模式

- 首次启动默认浏览本机 `C:` 盘，无需配置 SeaweedFS 服务。
- 支持在 `file:///C:/` 地址下浏览目录、创建文件夹、上传、下载和预览文件。
- 服务地址与根目录历史现在成对保存；切换地址时只显示对应的根目录。
- 旧版独立地址/根目录历史会在升级后安全清除，避免错误组合。

## 模型预览

- 改进渐变背景、三点光照、环境遮蔽、电影色调和自动贴合模型底部的地面网格。
- 右下角提供跟随相机方向变化的三维世界坐标轴。
- 使用右键拖动旋转、中键拖动平移、滚轮缩放，以及右键双击重置视角。

## 质量保障

- 增加本地文件系统后端与历史配置迁移测试。
- 保持 HTTP/SeaweedFS 访问和既有任务生命周期测试覆盖。
